# Угадай число

Игра в терминале на тему чисел: она загадывает число, вы угадываете, а она подсказывает — больше или меньше. Тексты и режимы — в [docs/game.json](docs/game.json), их можно менять без кода.

> [!WARNING]
> Нужен Node.js 24.12 или новее.

## Как запустить

```bash
npm install
npm start
```

`npm install` — один раз, `npm start` — собрать и сыграть. Выход из игры — Ctrl+C.

![Партия в терминале](images/screenshot.png)

## Режимы

| Режим | Диапазон | Победа |
|---|---|---|
| quick | 1–10 | молния! |
| classic | 1–100 | угадал! |
